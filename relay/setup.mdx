# Relay setup

## Prerequisites

- Node.js 18+
- `pnpm`
- MongoDB instance
- Access to upstream Tether API environment

## Local setup

### SendGrid inbound service

```bash
cd /Users/joshboyd/Code/tsuite/tether-relay-app/tether-relay/tools/sendgrid-inbound
pnpm install
pnpm dev
```

### Relay client

```bash
cd /Users/joshboyd/Code/tsuite/tether-relay-app/tether-relay/client
pnpm install
pnpm dev
```

## Verify startup

- Inbound service logs startup and webhook routes on configured port.
- Client app is reachable at the local Vite host.

## First checks

- `GET /webhook/health` returns `{"status":"ok"}`.
- Client can authenticate against configured backend URL.

Continue with [Environment variables](/relay/environment) before production use.
