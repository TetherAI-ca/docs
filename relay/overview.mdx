Tether Relay provides omnichannel messaging infrastructure and integration surfaces for inbound email and webchat.

## Surfaces

- **Operations UI**: manage configuration and monitor messaging workflows.
- **Inbound email service**: accept SendGrid parse webhooks.
- **Webchat widget**: deploy customer-facing chat to external sites.
- **Upstream API integration**: forward normalized events into Tether APIs.
