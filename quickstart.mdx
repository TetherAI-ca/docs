# Quickstart

This quickstart gets you from zero to a verified inbound webhook request.

<Info>
  You need Node.js 18+ and `pnpm` installed.
</Info>

## 1. Start the SendGrid inbound service

```bash
cd /Users/joshboyd/Code/tsuite/tether-relay-app/tether-relay/tools/sendgrid-inbound
pnpm install
PORT=3500 \
LOG_LEVEL=info \
MONGODB_URI='mongodb://localhost:27017/tether-relay' \
TETHER_API_URL='http://localhost:2212' \
INBOUND_EMAIL_DOMAIN='leads.staging.rvai.tetherai.ca' \
pnpm dev
```

## 2. Check service health

```bash
curl -s http://localhost:3500/
curl -s http://localhost:3500/webhook/health
```

Expected health response:

```json
{ "status": "ok" }
```

## 3. Send a test inbound email payload

```bash
curl -X POST "http://localhost:3500/webhook/sendgrid" \
  -F "from=sender@example.com" \
  -F "to=recipient@inbound.tether.com" \
  -F "subject=Quickstart test" \
  -F "text=Inbound test message from quickstart"
```

## 4. Verify forwarding behavior

Check service logs for:

- Parsed sender and recipient fields.
- Extracted `configurationId` from inbound address.
- Forwarding request to `${TETHER_API_URL}/api/webhook/outreach`.
